SPI 模試ドリル / MOCK TEST

本番と同じ形式で解いてみる

Answer under real test-center conditions: one timer per question, no going back.

受ける前に

あなたの試験（楽天モバイル ソフトウェアエンジニアリング／8月中旬）
日本語 120問 / 12分（1問6秒）＋ 英語 75問 / 65分、パート1は自宅オンライン、パート2は大田町で対面。

日本語セクションは覚えているかどうかを問う速度勝負なので、このドリルはそのままの速さでは再現していません。 ここで身につけるのは「解き方の型」です。型を知っていれば、本番で読んだ瞬間に答えが出せるようになります。 まず「解き方」をここで固め、そのあと語彙を反復して速度を上げる——この順番でいきましょう。

本番のルール（このドリルも同じにしてあります）

  • 1問ごとに制限時間があります。画面下のバーが 緑 → 黄 → 赤 と減っていきます
  • 時間切れになると、答えていなくても自動で次の問題に進みます
  • 前の問題には戻れません
  • 電卓は使えません。紙と鉛筆を用意して、筆算で計算してください

準備するもの / What you need

紙・鉛筆・静かな部屋。Paper, a pencil, and a quiet room. No calculator.

設定

長さ / Length

本番と同じ長さは、あなたの日本語セクションのペースを再現します。120問・全体で12分の一括タイマー（1問ごとの制限時間なし）。解き切れなくて当たり前で、速さの体感と「捨てて次へ行く」練習が目的です。言語問題から先に出ます。

分野 / Section

モード / Mode

毎回ちがう問題が出ます（まだ解いていない問題が優先されます）。分野の内訳も本番と同じ比率です。

※ 出題はレッスン用のオリジナル類題です。実際の試験問題ではありません。
