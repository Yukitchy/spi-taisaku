# SPI対策 レッスン教材・模試ドリル

日本語レッスン（Yuuki @ Anime Sensei）で使うSPI対策の教材です。

- `index.html` … レッスン教材（SPIの全体像・ミニ診断・解き方の型・頻出語彙）
- `drill.html` … 本番形式の模試ドリル。1問ごとの制限時間、時間切れで自動送り、前の問題に戻れない
- `questions.js` … 問題バンク（167問）。`node build.js` で `_gen_*.js` を結合して生成する

問題はすべてレッスン用に書き下ろしたオリジナル類題です。実際の試験問題ではありません。

## 問題を追加するとき

`_gen_なにか.js`（`[{...},{...}]` 形式の配列リテラル）を置いて

```
node build.js
```

同じ問題（分野＋本文＋設問文が同一）は自動で1つにまとめられるので、何度実行しても増殖しません。
